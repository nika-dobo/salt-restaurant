# Salt Restaurant | Terrace & Bar — Tbilisi

Multi-page responsive restaurant & terrace bar web application built with React 18, React Router (`HashRouter`), and Tailwind CSS.

## Features
- **5 Pages**: Home, Menu & Liquid Art Bar, Terrace & Events, Visual Gallery (Lightbox), Reservations & Google Maps
- **Interactive Menu Filtering** (Georgian & European cuisine, dietary tags, chef picks) & **Table Reservation Modal**
- **Bilingual Support** (`KA` / `EN`) via Context API

## Tech Stack
- React 18 · React Router · Tailwind CSS · Vite · Lucide Icons
